## Peta Event
| Komponen | Event | Isi handler |
|---|---|---|
| tambahButton, tambahItem | actionPerformed | memanggil tambah() |
| ubahButton, ubahItem | actionPerformed | memanggil ubah() |
| hapusButton, hapusItem | actionPerformed | memanggil hapus() |
| cariField | keyReleased | memanggil saring() |
| bukuTable | mouseClicked | klik dua kali memanggil ubah() |
| keluarItem | actionPerformed | menutup jendela |
| batalButton (dialog) | actionPerformed | menutup dialog |
| simpanButton (dialog) | actionPerformed | validasi lalu simpan |
